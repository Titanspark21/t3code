# Appearance

T3 Code includes a small set of reviewed themes for long coding sessions. Choose a theme from
**Settings → Appearance** on web or desktop, or from the Appearance screen in the mobile app.

The built-in themes are T3 Code, T3 Chat, Grove, Ocean, Ember, Iris, and OmniCode. Every theme
provides light and dark colors, so you can choose one theme for both appearances or pair different
themes with **System**, **Light**, and **Dark** mode.

OmniCode is a restrained slate-and-cyan palette designed for dark-mode work. It keeps the editor,
terminal, sidebar, status colors, and message actions on the same semantic palette rather than
changing only the page background.

Your appearance choice is stored locally on each client. It does not change the provider, project,
thread, or remote server settings.
